# One-Line Office Joke: 24-Hour Sprint

A single original one-line joke about office life, written for the
[make.fun bounty](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162).

> I asked everyone to stop hitting reply-all, by hitting reply-all.

`main.py` writes the joke to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`),
validating it first: UTF-8, 1–200 characters, a single line, not only
whitespace. Deterministic — no clock, randomness, environment input beyond
the output directory, or network; the same bytes every run.
